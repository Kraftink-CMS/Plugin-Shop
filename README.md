# Shop for KraftInk

Open a storefront for digital products such as server ranks, downloadable files and gift cards. Manage your products, orders and discounts from the KraftInk admin panel.

Install Shop from **Plugins** in the KraftInk admin panel, then open **Extensions → Shop** to configure your catalog and payments.
